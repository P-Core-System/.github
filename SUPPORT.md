# Support

Need help with a P-Core project? Here's where to find it.

## Bugs and feature requests

Open a **GitHub issue** in the relevant repository. The P-Core-System org is made up of these projects:

| Project | Purpose |
|---------|---------|
| [pcore-trader](https://github.com/P-Core-System/pcore-trader) | Automated crypto trading bot |
| [pcore-brain](https://github.com/P-Core-System/pcore-brain) | Reusable AI brain client |
| [pcore-assistant](https://github.com/P-Core-System/pcore-assistant) | AI-powered Telegram chat assistant |
| [pcore-webai](https://github.com/P-Core-System/pcore-webai) | Multi-provider web AI server |
| [pcore-orchestra](https://github.com/P-Core-System/pcore-orchestra) | Ambient multi-agent orchestration |

Please check existing issues first to avoid duplicates, and include repro steps and version info.

## Automation

For help with the P-Core orchestration / automation layer (agents, GitHub Actions, orchestration loops), reach out via the **P-Core orchestrator** — see `pcore-orchestra` for installation and usage.

## Security

For security vulnerabilities, follow the process in [`SECURITY.md`](SECURITY.md) — do not open a public issue.

## Maintainers

For anything else, contact the maintainers of the relevant repository or the P-Core-System org.
