# Security Policy

The P-Core project family includes **P-Core trading software** (`pcore-trader`) which automates real financial trading. Security issues here should be treated seriously — a vulnerability could lead to financial loss.

## Reporting a Vulnerability

Please **do not open a public issue** for security vulnerabilities. Report them privately:

- Open a **private vulnerability report** on the affected repository (GitHub → **Security** → **Report a vulnerability**), or
- Email the maintainers directly if a private report is not available.

Include the phrase **`[SECURITY]`** in the title of your report so it is triaged immediately.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (or a proof of concept)
- Affected version(s) / components
- Any suggested fix, if you have one

## Expected Response Time

- **Acknowledgment:** within **48 hours** of a report being received
- **Initial triage / severity assessment:** within **5 business days**
- We will keep you updated as we work on a fix.

## Disclosure

Do **not** disclose the vulnerability publicly until we have published a fix (or, in rare cases, explicitly agreed on a disclosure timeline). We aim to fix critical issues as quickly as possible given the financial nature of this software.

We appreciate responsible disclosure and the community's help keeping the P-Core ecosystem safe.
